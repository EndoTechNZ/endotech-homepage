MB2 cases often become difficult before the file reaches the canal. The clinical problem is not only apical anatomy; it is access, headroom, angulation, visibility, and the ability to keep the file aligned while entering a smaller secondary canal.

## Clinical Problem

Restricted MB2 access changes the practical demands of rotary instrumentation.

| Clinical constraint | Why it matters |
| --- | --- |
| Reduced coronal headroom | The handpiece has less room to align with the canal entrance. |
| Tight entry angle | The file is more likely to approach the orifice off-axis. |
| Limited visibility | Tactile control becomes more important during initial engagement. |
| Narrow canal entry | Glide path preparation must remain deliberate before shaping begins. |

In these cases, a standard-length file can feel less manageable before working length becomes the main issue.

## TransformX™ Solution

A shorter rotary glide path file can improve the access stage by making the handpiece easier to position and the canal entry easier to control.

The Acrobat MB2 option is designed for this clinical moment:

| File | Length | SKU | Role |
| --- | --- | --- | --- |
| Acrobat 15/.05 | 17 mm | ACGP-150517RF | Short glide path access file for MB2 and restricted-entry cases. |

The goal is not simply to use a smaller file. It is to establish a controlled, reproducible path before the clinician transitions into TransformX™ shaping.

## Key Features

- **17 mm working length option** supports improved handpiece clearance in restricted molar access.
- **15/.05 glide path sizing** gives a deliberate entry step before larger shaping files are introduced.
- **Acrobat sequence compatibility** keeps MB2 access inside the wider EndoTech glide path workflow.
- **Simple SKU identification** helps separate the MB2 access file from standard-length glide path options.

## Clinical Benefits

- Better coronal clearance when chamber anatomy limits handpiece position.
- More controlled canal entry where visibility and angle are compromised.
- Cleaner separation between negotiation, glide path confirmation, and shaping.
- A more predictable handoff into [TransformX™ ET Files](../../products/et-transformx/) or the wider shaping sequence.

## Where It Fits Clinically

Use the MB2 file concept when the access problem is part of the instrumentation problem:

- Maxillary molars with restricted MB2 access.
- Cases where the chamber layout limits handpiece angle.
- Canals where a shorter file improves control before deeper progression.
- Situations where coronal clearance affects confidence and consistency.
