MB2 access is often a control problem before it is a shaping problem. The clinician needs enough visibility, headroom, and file alignment to enter a small secondary canal without forcing the instrument off-axis.

<div class="clinical-guide-intro">
  <div>
    <span>Clinical aim</span>

    <p>A shorter access file can improve handpiece positioning when chamber anatomy limits angle, visibility, and tactile confidence.</p>
  </div>
  <div>
    <span>System logic</span>
    <strong>Control the entry before shaping begins.</strong>

  </div>
</div>

## Introduction

MB2 cases often become difficult before the file reaches the canal. The clinical problem is not only apical anatomy; it is access, headroom, angulation, visibility, and the ability to keep the file aligned while entering a smaller secondary canal.

<div class="clinical-guide-note">
  <span aria-hidden="true">i</span>
  <div>
    <strong>Access challenge</strong>
    <p>In restricted molar access, a standard-length rotary file can feel less manageable because the handpiece position and canal entry angle are working against the clinician.</p>
  </div>
</div>

Restricted MB2 access changes the practical demands of rotary instrumentation.

## TransformX™ Solution

A shorter rotary glide path file can improve the access stage by making the handpiece easier to position and the canal entry easier to control.

  <article>

## Where It Fits

Use the MB2 file concept when the access problem is part of the instrumentation problem: restricted maxillary molars, limited handpiece angle, compromised visibility, and cases where shorter file length improves control before deeper progression.

<div class="clinical-guide-fit">
  <strong>The objective is not simply to use a smaller file.</strong>
  <p>The objective is to establish a controlled, reproducible path before the clinician transitions into TransformX™ ET or PT shaping.</p>
