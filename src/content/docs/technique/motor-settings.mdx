<p class="clinical-guide-eyebrow">Technique guide</p>

Motor settings support clinical control, but they do not replace sequence discipline. Use the settings below as a practical reference, then adapt within the clinician's judgement for anatomy, access, irrigation, and file feedback.

<div class="clinical-guide-intro">
  <div>
    <span>Clinical aim</span>
    <strong>Keep rotary behaviour predictable.</strong>
    <p>Correct RPM and torque help the file work within its intended range while the clinician monitors resistance, glide path quality, and canal anatomy.</p>
  </div>
  <div>
    <span>System logic</span>
    <strong>Settings support the sequence.</strong>
    <p>Glide path files, Transform S™ ET, and Transform S™ PT each have a defined clinical role and should be used with light pressure and frequent irrigation.</p>
  </div>
</div>

## Clinical Problem

Incorrect settings can increase stress on the file and reduce tactile control. The problem is greatest when anatomy is curved, the glide path is incomplete, or the file is asked to progress under apical pressure.

<table class="clinical-guide-table">
  <thead>
    <tr>
      <th>Setting issue</th>
      <th>Clinical consequence</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        <strong>Too much apical pressure</strong>
        <span>Force replaces file feedback</span>
      </td>
      <td>Higher torsional demand and greater risk of abrupt engagement.</td>
    </tr>
    <tr>
      <td>
        <strong>Poor glide path control</strong>
        <span>Shaping file must negotiate anatomy</span>
      </td>
      <td>More canal stress and less predictable progression to working length.</td>
    </tr>
    <tr>
      <td>
        <strong>Ignoring resistance</strong>
        <span>Motor data not treated as feedback</span>
      </td>
      <td>Reduced ability to respond before transportation or file fatigue develops.</td>
    </tr>
  </tbody>
</table>

## Transform S™ Solution

Transform S™ is designed to preserve familiar rotary technique while adding more controlled shaping behaviour. The settings below keep each file inside its intended clinical role.

<div class="clinical-guide-sequence">
  <article>
    <span>01</span>
    <strong>Confirm glide path</strong>
    <p>Use Micro-Path at 300 RPM and 2.0-2.5 Ncm before asking shaping files to work at length.</p>
  </article>
  <article>
    <span>02</span>
    <strong>Shape with light pressure</strong>
    <p>Use Transform S™ ET or Transform S™ PT at the recommended torque and let file feedback guide each pass.</p>
  </article>
  <article>
    <span>03</span>
    <strong>Reset between files</strong>
    <p>Irrigate, recapitulate, re-irrigate, then re-enter only when the canal path feels reproducible.</p>
  </article>
</div>
