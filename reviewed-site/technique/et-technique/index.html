The file is introduced after the clinician has evidence that the canal path is real, reproducible, and safe to shape. That is where Avatar Tip and FlexION Technology become clinically useful rather than merely technical features.

MB2 and curved-canal use cases

Two hard anatomies. One shaping principle.

MB2 canals

A hidden path needs a file that can stay calm.

MB2 canals are narrow, curved, and easy to overload. Once the path is confirmed, FlexION Technology helps the file respond with greater adaptability instead of locking into the wall, reducing unnecessary torsional stress and helping protect against fatigue and separation.

Review MB2 protocol
Curved canals

A curved path needs repeatability before load.

In curved canals, the advantage is load management. The file follows a glide path that already returns to length, then shapes with short, clean, reassessed engagement.
