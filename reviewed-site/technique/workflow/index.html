Between Each File

Irrigate, recapitulate, re-irrigate.

This remains the simplest high-value discipline in the sequence. It supports debris removal, patency, and preparation continuity before the next rotary file is introduced.

Key review points

  1. 1

    Irrigate thoroughly before advancing to the next file.

  2. 2

    Recapitulate with a small hand file to confirm patency.

  3. 3

    Re-irrigate before continuing the rotary sequence.
